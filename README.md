# 한다영 포트폴리오

시각영상디자인 · 기획 · 디자인 포트폴리오 (Next.js + Tailwind)

## 라이브 사이트

배포 후 아래 주소로 확인할 수 있습니다.

**https://natsu0701.github.io/portfolio/**

> GitHub 저장소 페이지는 코드만 보여 줍니다. 웹사이트는 위 Pages 주소를 사용하세요.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 정적 사이트를 빌드해 GitHub Pages로 배포합니다.
